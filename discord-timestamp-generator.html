Discord timestamp formats

Written as <t:UNIX:style>. Discord lists nine styles in its developer reference, including the newer s and S. Examples show that reference's format; the real text follows each reader's Discord settings.

How Discord timestamps work

A timestamp stores one moment as a Unix time, the seconds since 1 January 1970 UTC. Discord turns it into each reader's local time, so nobody has to convert anything.

Say your event is at 8:00 PM in New York and you are in Madrid. Set the date and time, choose New York as the zone, and copy the code. Everyone sees the right local time, including you.

Paste the code anywhere Discord accepts text. It only renders inside Discord: elsewhere it stays as raw text. To check a code someone sent you, paste it into Read a timestamp above.

Frequently asked questions

What is a Discord timestamp?+

A code, <t:UNIX:style>, that Discord displays as a date or time in each reader's own time zone.

How do I make one for a time in another time zone?+

Enter the date and time, then choose the zone or city that time belongs to. The code stores the exact moment, so it is correct for everyone regardless of where you are.

Which format should I use for an event?+

Combine a full date with a countdown: <t:UNIX:F> (<t:UNIX:R>). Readers see the exact time and how long is left. The ready-made messages above build this for you.

What is the default style?+

f, long date and short time. Discord uses it when you write <t:UNIX> with no letter.

Why does my timestamp show as plain text?+

Check that it has both angle brackets and no spaces, like <t:1618935630:F>, and that the number is in seconds rather than milliseconds. Codes do not render inside code blocks or outside Discord.

Does the relative format update by itself?+

Yes. <t:UNIX:R> counts down or up without anyone editing the message.

How do I make a Discord timestamp?+

Pick the date and time above, choose a format and copy the code, for example <t:1767225600:F>. Paste it into any message and Discord shows it in each reader's own time zone.

How do I put a dynamic time in a Discord message?+

Use the relative style, <t:UNIX:R>. Discord shows it as "in 3 hours" or "2 days ago" and keeps it up to date by itself.

Is there a Discord command for timestamps?+

Discord has no built-in timestamp command. You type the code by hand or copy it from a generator like this one. Some bots add a command, but the code they post is the same.
